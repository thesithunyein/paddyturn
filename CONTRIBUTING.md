# Contributing to PaddyTurn

Use a [GitHub issue](https://github.com/thesithunyein/paddyturn/issues) for bugs and feature proposals. Use the [security policy](SECURITY.md) for vulnerabilities.

1. Install dependencies with `npm ci` using Node.js 24.
2. Create a branch and keep the change focused.
3. Run `npm test` and `npm run build`. For interface changes, check the queue, weather controls, and history at desktop and mobile widths.
4. Open a pull request describing the behavior change and how you checked it.

Use synthetic or anonymized batches in screenshots and reproduction steps. Follow the [code of conduct](CODE_OF_CONDUCT.md).
